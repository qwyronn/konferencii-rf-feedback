Проект «Конференции.РФ» — практическая работа № 2
Форма обратной связи (Vue 3 + Vite)

Запуск проекта:
1. npm install
2. npm run dev
3. Открыть адрес, который покажет Vite (http://localhost:5173)

Сборка для продакшена: npm run build

Структура:
- src/App.vue — страница просмотра заявок, кнопка «Оставить отзыв»
- src/components/FeedbackModal.vue — модальное окно формы обратной связи
- src/components/ToastNotification.vue — toast-уведомление

Git:
В репозитории выполнены два коммита — начальный и итоговый.
Чтобы отправить репозиторий на GitHub:
  git remote add origin <адрес вашего репозитория>
  git push -u origin master
